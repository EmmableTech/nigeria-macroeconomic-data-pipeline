Project Documentation

This directory contains the technical documentation for the Nigeria Macroeconomic Indicators Data Pipeline.

Purpose

The documentation explains the design, data sources, workflow, tools and implementation of the pipeline. It provides a clear guide for understanding how the project collects, processes, stores and validates economic data.

Documentation Contents

The following documents will be maintained in this directory:

1. Project Architecture: Description of the pipeline components and how data flows between them.
2. Data Sources: Details of the World Bank API and the economic indicators selected for the project.
3. Data Dictionary: Explanation of the fields, data types and meanings of the collected datasets.
4. Pipeline Workflow: Step-by-step explanation of data extraction, storage, cleaning and transformation.
5. Data Quality Rules: Description of the checks used to assess data completeness, accuracy and consistency.
6. Setup Guide: Instructions for installing dependencies and running the pipeline.

Project Scope

The project focuses on selected Nigerian macroeconomic indicators, including GDP growth, inflation and population. It uses publicly available data and open-source technologies.

Documentation Status

Documentation will be updated as the pipeline is developed, tested and improved.
